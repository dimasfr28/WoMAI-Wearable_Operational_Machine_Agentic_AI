# Bot API (Agentic AI Chatbot) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the new `POST /bot` and session management API (`/bot/sessions`), featuring a LangGraph-based agentic AI chatbot that queries CNC sensor run data via a dedicated ChromaDB RAG collection (`bot_sensor_data`) and streams responses using Server-Sent Events (SSE).

**Architecture:** A directed LangGraph state graph consisting of Router -> Resolve Machine / Chitchat -> Sensor Tools ReAct sub-loop -> Synthesize & Stream. Conversation history and rooms are persisted in dedicated `bot_sessions` and `bot_messages` PostgreSQL tables. RAG retrieval searches the `bot_sensor_data` ChromaDB collection embedded via multilingual MiniLM.

**Tech Stack:** FastAPI, SQLAlchemy 2.0, Alembic, PostgreSQL, ChromaDB, LangGraph, Groq API, sentence-transformers, Pydantic v2.

**Spec:** `docs/superpowers/specs/2026-08-15-bot-api-design.md`

## Global Constraints

- Backend only (no frontend code changes in this phase).
- Database models: Use dedicated `bot_sessions` and `bot_messages` tables with Alembic revision `0011`.
- Vectorstore: Collection name `bot_sensor_data` configured via `settings.CHROMA_COLLECTION_BOT_SENSOR`.
- Auth: Require JWT authentication (`require_role("viewer")` or `get_current_user`).
- Response format: SSE streaming with event types `status`, `tool_call`, `needs_input`, `text`, `error`.
- DB session in SSE: Use `SessionLocal()` inside generator to prevent premature session closure.

```python
from __future__ import annotations
import logging
from app.ingestion.embedder import embed_texts
from app.vectorstore.chroma_client import get_bot_sensor_collection

logger = logging.getLogger(__name__)


def search_bot_sensor_data(
    query_text: str,
    machine_id: str | None = None,
    k: int = 5,
) -> list[dict]:
    """Semantic search against the dedicated bot_sensor_data collection."""
    collection = get_bot_sensor_collection()
    if collection.count() == 0:
        return []

    embedding = embed_texts([query_text])[0]
    where_filter = {"machine_id": machine_id} if machine_id else None

    try:
        results = collection.query(
            query_embeddings=[embedding],
            n_results=min(k, collection.count()),
            where=where_filter,
        )
    except Exception:
        logger.exception("search_bot_sensor_data: query failed")
        return []

    docs = results.get("documents", [[]])[0]
    metas = results.get("metadatas", [[]])[0]
    distances = results.get("distances", [[]])[0]

    items = []
    for doc, meta, dist in zip(docs, metas, distances):
        items.append({
            "content": doc,
            "metadata": meta or {},
            "similarity": round(1.0 - float(dist), 4) if dist is not None else 0.0,
        })
    return items
```
